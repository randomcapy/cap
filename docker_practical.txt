Practical 06: Implement Docker Commands

Step 1: Install Docker Desktop - Download Docker Desktop for Windows
from official website - Install and launch Docker

Step 2: Verify Docker Installation Command: 
docker –version

Step 3: Create Flask App from flask import Flask

from flask import Flask

app = Flask(__name__)

@app.route('/')
def hello():
    return "Hello Version 1"

app.run(host="0.0.0.0", port=5000)

Step 4: Create Dockerfile File name: 
Dockerfile

Contents:
 FROM python:3.9

WORKDIR /app

COPY . .

RUN pip install flask

CMD [“python”, “app.py”]


Step 5: Build Docker Image Command:
 docker build -t flaskapp:v1 .

Step 6: Run Docker Container Command: 
docker run -p 5000:5000 flaskapp:v1

Step 7: Verify Output Open browser: 
http://localhost:5000

Output:
 Hello Version 1

Step 8: Check Running Containers (Optional) Command: 
docker ps

Commands Summary: docker –version docker build -t flaskapp:v1 . docker
run -p 5000:5000 flaskapp:v1 docker ps
